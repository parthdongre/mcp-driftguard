# Verified literature review and novelty assessment

Evidence cutoff and retrieval date: **2026-10-15**. This covers material available by this date, not the remainder of October. Publication status means verified publisher metadata where linked; an arXiv listing alone is treated as a preprint. Author-reported measurements below are context, not DriftGuard measurements or a quantitative comparison.

## Search and screening protocol

The review started with the eight supplied arXiv identifiers, the official MCP specification, Interlock, and MCPoison. Targeted searches then covered recent descriptor evolution, schema drift, approval, temporal attacks, and sequential detection. Primary sources were preferred: arXiv originals/full text, ACL Anthology, PMLR, publisher DOI pages, official specifications, author repositories, and the original vulnerability disclosure. News summaries and social-media claims were excluded as evidence.

Representative reproducible queries were `"Interlock" "Model Context Protocol"`, `site:arxiv.org "MCP" "drift" "2026" "September"`, `site:arxiv.org "MCP" "temporal" security "October"`, each exact methodological title below, and `site:aclanthology.org "MCP-Guard"`. Search-index recall is incomplete. This is a structured targeted review, not a claim of exhaustive indexing or a fabricated PRISMA count. Rerun it before submission and archive search exports and the exact PDF/repository revisions.

## Sequential-method evidence matrix

| Method and verified reference | Formulation/evidence and assumptions | Relevance and constraint |
|---|---|---|
| Wei and Xie, **Online Kernel CUSUM for Change-Point Detection**, [arXiv:2211.15070v6](https://arxiv.org/abs/2211.15070v6); JRSSB 2026, [DOI 10.1093/jrsssb/qkag020](https://doi.org/10.1093/jrsssb/qkag020). | Kernel statistics over candidate windows; recursive evaluation and analytic ARL/delay approximations. Bounded window choices matter to compute cost and power. | Candidate for nonlinear joint capability drift. The current scalar/coordinate CUSUM implementations do not reproduce this paper. Freeze kernel/bandwidth/windows on clean development data. [Author code](https://github.com/SongWei-GT/online_kernel_cusum) was identified, not executed. |
| Adams and MacKay, **Bayesian Online Changepoint Detection**, [arXiv:0710.3742v1](https://arxiv.org/abs/0710.3742v1), 2007, preprint. | Run-length posterior recursion with a hazard function and predictive model; demonstrates three real datasets. | Attractive uncertainty and explicit onset inference. Exact history grows with time; truncated runs trade fidelity for bounded compute. Independent segment parameters, hazard and observation model need justification for adversarial descriptor trajectories. |
| Shaer, Bar, Prinster and Romano, **Testing For Distribution Shifts with Conditional Conformal Test Martingales**, **ICML 2026**, PMLR 306:109447–109469, [publisher](https://proceedings.mlr.press/v306/shaer26a.html), [arXiv:2602.13848](https://arxiv.org/abs/2602.13848). | Fixed null reference avoids post-change reference contamination; robust construction accounts for finite-reference estimation error and provides conditional validity under stated assumptions. | Closely matches retaining a clean approved baseline. Serial dependence, adaptive updates and heterogeneous repositories require checking; naive fixed-reference conformal ranks do not automatically form a valid martingale. [Author code](https://github.com/shaersh/cctm) identified, not executed. |
| Eliades and Papadopoulos, **Multivariate Change-Point Detection Using Feature-Based Inductive Conformal Martingales**, **COPA 2026**, PMLR 329:633–651, [publisher](https://proceedings.mlr.press/v329/eliades26a.html). | Ellipsoidal k-nearest-neighbor nonconformity with Mahalanobis distance; four real datasets with inserted change points plus air-quality recalibration. | Candidate nonconformity for structured drift vectors. Small high-dimensional references make covariance/density estimates unstable; exchangeability-based assurances cannot be asserted for arbitrary adversarial sequences. |
| Bhattacharyya and Ramdas, **Change detection with conformal martingales: new optimal constructions, and suboptimality of existing methods**, [arXiv:2609.27179v1](https://arxiv.org/abs/2609.27179v1), 2026-09-23, preprint. | Analyzes independent observations and unknown pre/post distributions, showing poor delay in standard constructions and proposing improved conformal e-processes/e-detectors. | False-alarm validity does not imply acceptable detection delay. Must compare both at matched false-alarm budgets; theoretical rates cannot be transferred to dependent tool-version sequences without checking conditions. |
| Howard, Ramdas, McAuliffe and Sekhon, **Time-uniform, nonparametric, nonasymptotic confidence sequences**, **Annals of Statistics 49(2):1055–1080**, 2021, [DOI 10.1214/20-AOS1991](https://doi.org/10.1214/20-AOS1991), [arXiv:1810.08240](https://arxiv.org/abs/1810.08240). | Time-uniform inference under specified concentration/martingale conditions. | Useful foundation for sequential uncertainty and optional stopping. A sequence of ordinary bootstrap intervals is not a confidence sequence. Current cluster bootstrap is for frozen evaluation summaries, not online trust decisions. |

## Timeline and gap assessment

| Period | Evidence that changes positioning |
|---|---|
| August 2025 | MCPoison establishes post-approval trust bypass; MCP-Guard and MCPTox establish semantic defense and metadata attack evaluation. |
| January–April 2026 | Implicit adaptive poisoning, historical runtime trust calibration and formal capability/security frameworks narrow broad novelty claims. |
| June–August 2026 | Description/code consistency, evidence-grounded runtime scanning, revised MCP protocol and staged result drift become established topics. |
| September–15 October 2026 | FCD directly addresses descriptor/handler epoch mismatch; conditional/feature conformal methods and updated delay theory strengthen the methodological comparison required. Interlock visibly overlaps with product drift control. |

The defensible research question is whether **capability-aware and consent-aware version-sequence classification reduces unnecessary re-consent at matched malicious recall**, including bounded low-and-slow attacks. This is a hypothesis. The combined C0/C1/C2/C3 label task, honest longitudinal benchmark and matched-policy comparison may become contributions only after independent evidence supports them.

Do not claim first semantic MCP guard, first temporal defense, first post-approval drift detector, first quarantine gateway, or novel use of CUSUM. A descriptor change detector cannot prove unchanged implementation behavior, prevent client bypass, or protect a stdio server's host process merely by mediating MCP messages.

## Protocol and artifact implications

Official [2026-07-28 release notes](https://blog.modelcontextprotocol.io/posts/2026-07-28/) describe stateless requests, `server/discover`, routing headers and cache hints. The versioned [TypeScript SDK migration guide](https://ts.sdk.modelcontextprotocol.io/v2/migration/support-2026-07-28) and [Python cache documentation](https://py.sdk.modelcontextprotocol.io/client/caching/) are primary implementation references.
